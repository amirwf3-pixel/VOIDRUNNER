## ✨ ویژگی‌ها در یک نگاه

- 🎲 **تولید رویه‌ایِ قطعی** — هر seed همیشه همان سکتور را می‌سازد؛ بازتولید ۱۰۰٪ یکسان (۱۸۰/۱۸۰)
- 💾 **ذخیره/ادامهٔ دقیق** — خروج در هر چک‌پوینت سکتور، ادامهٔ بدون خطا، بدون جایزهٔ تکراری
- 👑 **هدف «ترور فرمانده»** — شکار یک نخبهٔ محافظت‌شده با مارکر متحرک روی خود هدف
- 💀 **دو میدان باس با هویت مستقل** — چرخهٔ STOKE (۳ فاز) و چرخهٔ MELTDOWN (۴ فاز)
- 🧬 **۷ پروفایل تهدید و نخبه‌های توانادار** — ترکیب دشمنان و میدان نبرد در هر عمق تغییر می‌کند
- 🔊 **صدا و جلوه‌های رویه‌ای** — بدون هیچ فایل بیرونی؛ همه‌چیز در زمان اجرا ساخته می‌شود
- 📦 **صفر وابستگی** — فقط Node.js برای اجرا و تست؛ بدون مرحلهٔ build

<a id="gameplay"></a>
## 🎮 گیم‌پلی و امکانات

- **پیشروی عمقی:** از سکتور ۱ تا ۶؛ هر سکتور عمیق‌تر، گران‌تر و خطرناک‌تر از قبلی
- **اهداف متنوع سکتور:** پاک‌سازی، بازیابی داده، انهدام هدف، ترور فرمانده، و میدان باس
- **مبارزهٔ سلاح‌محور:** ۵ ردهٔ مهمات، خشاب‌گذاری، تعویض سریع سلاح، و بازخورد ضربهٔ لحظه‌ای
- **نخبه‌ها و گروه‌های نبرد:** نخبه‌ها توانایی اختصاصی دارند (سپر، احضار، شلیک قوسی و…) و سردroomها همیشه محافظ دارند
- **غارت پرریسک/پربار:**
  طاق‌های ویژه (Vault) غارت گران‌بها با کیفیت و شانس نادر بودن بالاتر می‌دهند — اگر زنده بیرون بروی
- **پیشرفت دائمی:** XP هدف و XP تراشه، Perk تا سطح ۲۰، سلاح‌های tier-محور به عمقِ رسیده
- **اقتصاد مرگ:** مرگ یعنی از دست رفتن بخش بزرگ غارت؛ استخراج موفق یعنی نگه‌داشتن همه‌چیز

<a id="quickstart"></a>
## 🚀 اجرای بازی

پیش‌نیاز: **Node.js ≥ 18** — بدون build، بدون نصب وابستگی.

```bash
npm start          # یا معادل: node tools/serve.mjs
```

سپس در مرورگر: **http://localhost:4173**

<sub>هر وب‌سرور استاتیک دیگری هم کار می‌کند (مثل `python3 -m http.server 4173`).
به‌دلیل استفاده از ES Modules، باز کردن مستقیم `index.html` با `file://` کار نمی‌کند.</sub>

<a id="structure"></a>
## 🗂 ساختار پروژه

```
VOIDRUNNER/
├─ index.html            # نقطهٔ ورود
├─ styles.css
├─ package.json          # اسکریپت‌های اجرا و تست — صفر وابستگی
├─ src/
│  ├─ main.js            # بوت و حلقهٔ اصلی بازی
│  ├─ config/            # بالانس، سلاح‌ها، دشمنان، پالت
│  ├─ core/              # ورودی، رویدادها، RNG قطعی
│  ├─ generation/        # تولید رویه‌ای سکتورها و اهداف
│  ├─ world/             # tilemap و برخوردها
│  ├─ game/              # اجرا، اهداف، مبارزه
│  ├─ enemies/           # AI، نخبه‌ها، میدان و موج باس
│  ├─ weapons/           # سلاح‌ها و پرتابه‌ها
│  ├─ loot/              # غارت و اقتصاد
│  ├─ progression/       # پیشرفت دائمی و تسویهٔ اجرا
│  ├─ effects/ audio/    # ذرات، دوربین، صدای رویه‌ای
│  ├─ render/ ui/        # رندر Canvas و رابط کاربری
│  └─ save/              # ذخیره / ادامه
└─ tools/                # سرور محلی، تست، smoke
```
